      How this works

      1) Pick the project ML configuration using the Project combo.

      2) Review clusters (collapsed by default). Each cluster shares the same predicted value; one issue is the Centroid.

      3) Confirm by agreeing to the centroid’s predicted value to confirm the cluster.

      4) If you disagree, choose a new value and/or leave a comment, then click Apply Change.

      5) Click Save & Trigger New Iteration (auth required) to lock this iteration and start a new one.

      6) Use Send Confirmed Data to Jira only when all iterations are confirmed.
